Green — PreparationCleaning, validation, and transformations.

How to use

Explore the 3D space

Choose a scene, rotate it with your mouse or finger, and zoom with the wheel or pinch gesture. Click any object to see its explanation. Use Reset camera to return to the initial view.

01 · DATA

Rows contain records. Columns describe properties. Features are the information used as model inputs.

02 · MODEL

A model learns a mapping or structure from examples. A neural network is one family of model.

03 · EVIDENCE

Evaluation tests performance using a suitable protocol and data not used to fit the final model.
